- **P0 — An anchor can move to an unrelated copy of its text.** [Candidate ordering](/workspace/kb-research/samples/skeletor/skeletor-orig/base-libs/text/Anchor.ml:348) breaks equal matches by document ID, with no preference for the anchor’s current document. If that document still contains the anchored text after an edit, an older indexed document with the same text can win the tie. The anchor then appears current at the wrong location.

- **P0 — A moved anchor can remain stale because its destination is indexed later.** [Relocation runs only for anchors on the document being updated](/workspace/kb-research/samples/skeletor/skeletor-orig/base-libs/text/Text.ml:211). The update command [processes files one at a time](/workspace/kb-research/samples/skeletor/skeletor-orig/cli/Documents_update_cmd.ml:438). If the original file is processed before the destination, relocation fails; indexing the destination does not retry that anchor. It remains stale until its original document changes again.
