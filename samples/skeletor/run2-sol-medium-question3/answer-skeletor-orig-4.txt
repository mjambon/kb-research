- **P0 — A move can leave an anchor permanently outdated when the destination is indexed later.** Relocation only retries anchors attached to the document being updated ([Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-orig/base-libs/text/Anchor.ml:525)). If the old file is deleted or rewritten before the destination receives the text, the failed attempt is recorded; indexing the destination does not retry that anchor. The same move can therefore succeed or fail depending on update order.

- **P0 — An unchanged anchor can jump to an unrelated copy.** Candidates are ranked by matched coverage, hit count, then document ID, with no preference for the anchor’s current document ([Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-orig/base-libs/text/Anchor.ml:348)). If an older indexed file contains the same passage, an edit elsewhere in the anchor’s own file can make the anchor relocate to that older file even though its original text is still present.
