I found four potential anchor relocation issues:

- **P0 — An anchor can silently move to unrelated evidence.** Relocation chooses the candidate with the most matching shingles, without preferring the original document or checking whether a cross-document move is plausible. If the original text is replaced and another document contains the same block, the anchor moves there and becomes up to date. This behavior is demonstrated by an existing [test](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/tests/Text_api_tests.ml:1098); the selection is in [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:348).

- **P1 — A failed move is not retried when its destination appears later.** A failed attempt records the source revision. Later indexing of a destination document only checks anchors assigned to that destination, while the source anchor no longer qualifies for retry at the same revision. File update order can therefore leave a recoverable anchor outdated until its source changes again. See [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:490), [Text.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Text.ml:211), and [DB.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/DB.ml:852).

- **P1 — Short anchors can miss an exact shifted match.** Documents index 16-byte shingles every 8 bytes, but a 16-byte anchor has only one query shingle. Inserting one byte before an anchor can place its unchanged text at an unindexed offset, yielding no candidate. See [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:167).

- **P1 — Repeated text can have no relocation candidates.** Shingles occurring more than once in a document are all discarded. An anchor made of repeated text can therefore become outdated after a simple position shift even when its full text remains present. See [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:152).
