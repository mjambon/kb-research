Relocation searches all indexed files and selects **one** candidate. It ranks matches by text coverage, then matching hit count; if those tie, it chooses the lowest document ID. There is no preference for the anchor’s original file and no ambiguity check, so an exact copy in another file can win. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:348)

The deterministic choice is useful, but automatically treating a duplicate as the same passage is risky. A test documents the resulting false positive: an anchor relocates to an unrelated file containing the same text. For trustworthy anchors, an exact match in the original file should take priority; otherwise, equally plausible files should prompt review rather than an arbitrary relocation. [Text_api_tests.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/tests/Text_api_tests.ml:1096)
