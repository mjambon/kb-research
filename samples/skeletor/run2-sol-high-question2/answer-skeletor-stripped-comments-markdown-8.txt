If the anchor text matches in multiple indexed files, relocation chooses **one** destination. It ranks candidates by matched text coverage, then matching hits, then lowest document ID; it does not prefer the original file or flag a tie as ambiguous. The anchor is updated to the first candidate. ([Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:348), [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:483))

That is deterministic, but it is risky for evidence anchors: identical text alone cannot establish which copy is the intended source. A regression test explicitly records relocation to an unrelated file as a known false positive. A safer policy would preserve a matching original location and treat equally strong matches elsewhere as ambiguous for review.
