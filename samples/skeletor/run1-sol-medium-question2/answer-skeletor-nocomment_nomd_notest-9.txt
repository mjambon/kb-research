When multiple files contain the anchor text, relocation **chooses one automatically**. It ranks candidates by matched shingle coverage, then hit count, then lowest document ID. It does not prefer the original file or flag a tie for review. The chosen file becomes the anchor’s new location. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-nocomment_nomd_notest/base-libs/text/Anchor.ml:348)

The deterministic tie break is useful, but the relocation itself can be wrong: identical text does not establish which copy the anchor refers to. The tests document a case where an anchor moves to an unrelated file containing the same text. [Text_api_tests.ml](/workspace/kb-research/samples/skeletor/skeletor-nocomment_nomd_notest/base-libs/text/tests/Text_api_tests.ml:1096) A safer policy would prefer the original file when evidence is equal and flag unresolved matches across files for review.
