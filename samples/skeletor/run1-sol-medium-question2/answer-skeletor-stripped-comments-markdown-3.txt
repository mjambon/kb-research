When multiple files contain the anchor text, relocation **selects one candidate**. It ranks candidates by matched text coverage, then by the number of matching shingles; a tie goes to the lowest document ID. It gives the original file no preference and does not flag the choice as ambiguous. That is useful when text truly moved, but undesirable when identical text appears in unrelated files: the anchor can silently move to the wrong one. A test records exactly that false positive. Ambiguous matches should generally remain unresolved for review unless other evidence distinguishes the destination.
