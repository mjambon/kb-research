If multiple files contain the anchor text, relocation chooses **one** candidate automatically. It ranks candidates by matched text coverage, then matching hit count, then lowest document ID. It gives the original file no preference and does not flag the result as ambiguous. ([Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-sitemap/src/skeletor/base-libs/text/Anchor.ml:348), [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-sitemap/src/skeletor/base-libs/text/Anchor.ml:483))

That is deterministic, but it is not always desirable: identical text cannot establish which copy the anchor refers to, so the anchor can move to an unrelated file. The tests explicitly identify this as a known false positive. A safer policy would keep a valid match in the original file and flag unresolved cross-file ties for review.
