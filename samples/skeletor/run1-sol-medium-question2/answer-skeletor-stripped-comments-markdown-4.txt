When multiple files qualify as relocation candidates, the code picks **one**: highest matched coverage, then most inlier hits, then lowest document ID. It does not prefer the original file or flag a tie as ambiguous. The anchor is updated to the chosen file and treated as up to date. [Selection code](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:348) · [Relocation code](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:483)

The deterministic choice is useful, but **automatic relocation across equally plausible files is undesirable for an evidence anchor**: identical text does not establish that the evidence moved. A test documents the resulting false positive, where an anchor moves to an unrelated file containing the same block. [Test](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/tests/Text_api_tests.ml:1096) A safer policy would keep an exact match in the original file when available and require review when cross-file matches remain ambiguous.
