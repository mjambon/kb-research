If anchor text matches in multiple files, relocation **chooses one file automatically**. It ranks candidates by matched text coverage, then by the number of matching hits; a tie goes to the lowest document ID. It gives the original file no preference and does not flag the ambiguity for review. That is risky for evidence anchors: identical text does not establish which copy the anchor refers to. A test documents a case where an anchor moves to an unrelated file containing the same boilerplate. A safer policy would keep the original location when it remains a valid match and leave genuinely ambiguous moves for review.
