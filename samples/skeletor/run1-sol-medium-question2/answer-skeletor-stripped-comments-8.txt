When multiple files qualify, relocation **chooses one automatically**. It ranks candidates by matched text coverage, then by the number of matching hits, and finally by the lowest document ID. It does not flag a tie or prefer the anchor’s original file; the selected file becomes the anchor’s new location. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:348)

That is deterministic, but it is **not desirable for ambiguous exact copies**. Identical text alone cannot establish which file the anchor was meant to follow, so the anchor can silently move to an unrelated copy. A test documents that outcome as a known false positive. In a tie, keeping the anchor in its original file when it still matches, or leaving an ambiguous move for review, would better preserve its meaning. [Text_api_tests.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/tests/Text_api_tests.ml:1096)
