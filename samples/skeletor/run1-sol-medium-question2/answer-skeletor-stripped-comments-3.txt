When multiple files match the anchor text, relocation picks **one automatically**. It ranks candidates by matched text coverage, then matching hit count, then lowest document ID. There is no preference for the original file and no ambiguity check; the anchor is updated to the winner. That is deterministic, but it can be wrong. An unrelated file can contain the same text, and a test documents exactly that false positive. When candidates are equally convincing, keeping the anchor for review would be safer than treating an arbitrary tie break as evidence that the text moved.
