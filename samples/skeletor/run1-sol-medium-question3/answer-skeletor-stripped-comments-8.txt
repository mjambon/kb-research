I found four potential issues:

- **P0 — An unrelated edit can move an anchor to another document.** Candidates with equal coverage and hit counts are ranked by document ID, with no preference for the anchor’s current document. If an earlier indexed document contains the same passage, editing text *outside* the anchor in its current document can silently move the anchor to that earlier document, even though the original passage is still present. The code also has a test documenting a related false positive. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:348)

- **P1 — A stale anchor is not retried when its text appears in a different document.** Updating a document retries only anchors already assigned to that document. If an anchor becomes stale in A and the passage is later added to B, indexing B never considers the anchor; it stays stale until A changes again. [Text.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Text.ml:211) · [DB.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/DB.ml:852)

- **P1 — Repeated text can make an intact anchor unfindable.** Indexing discards *every* occurrence of a shingle that repeats within a document. Adding a second copy of an anchored passage can therefore remove all its lookup shingles, causing relocation to mark the original anchor outdated despite its text remaining intact. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:152)

- **P1 — Recovery at the same range is omitted from update results.** Relocation updates the stored revision but returns the anchor only when its document, range, or text changes. Re-adding a deleted document with the original passage at the original range restores the anchor to current status without including it in the returned changes; the update command can then report the old outdated anchor as “unorphaned.” [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/base-libs/text/Anchor.ml:500) · [Documents_update_cmd.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments/cli/Documents_update_cmd.ml:471)
