- **P0 — An anchor can move away from text that still exists in its original document.** Relocation searches all documents, and equal matches are resolved by lowest document ID, with no preference for the original document. If two files contain the same passage and the original file has the higher ID, editing elsewhere in that file moves its anchor to the other file. The anchor then appears current at the wrong source. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:348)

- **P1 — Relocation depends on document update order.** Only anchors belonging to the document being updated are retried. If the old document is deleted or edited before a new destination is indexed, relocation fails; indexing the destination later does not retry that anchor. [Text.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Text.ml:211) [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:525)

- **P1 — Duplicating an anchored passage can make both copies unfindable.** The index drops every shingle that occurs more than once in a document. Appending a second copy of an anchored passage can therefore remove all of that passage’s search hits, leaving the anchor outdated even though its original text is intact. [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:152)
