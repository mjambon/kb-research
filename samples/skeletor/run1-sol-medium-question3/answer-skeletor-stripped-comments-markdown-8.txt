- **P0 — An unrelated copy can take over an anchor.** Relocation ranks all matching documents by coverage and hit count, then breaks ties by lowest document ID; it gives the original document no preference. If an older document contains the same anchored text, editing unrelated content in the original can move the anchor to that copy even while the original text remains intact. See [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:348).

- **P1 — A failed relocation is not retried when a destination appears.** A failed attempt records the original document’s revision. Relocation then runs only for anchors attached to the document being updated. If the original is removed before its replacement is indexed, adding the replacement leaves the anchor outdated until the original document changes again. See [Anchor.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Anchor.ml:490) and [Text.ml](/workspace/kb-research/samples/skeletor/skeletor-stripped-comments-markdown/base-libs/text/Text.ml:208).
