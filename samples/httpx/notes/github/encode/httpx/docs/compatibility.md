# Explain requests compatibility guide

tags: api docs

Explains where HTTPX usage differs from Requests, including redirects, client instances, URL handling, content upload, response encoding, authentication, and exceptions. This is migration guidance rather than a promise of exact Requests compatibility. Relevant behavior spans `/github/encode/httpx/httpx/_client.py`, `/github/encode/httpx/httpx/_models.py`, and `/github/encode/httpx/httpx/_urls.py`. Published via `/github/encode/httpx/mkdocs.yml`.
