# Explain troubleshooting

tags: docs transport

Describes concrete proxy failures, including HTTPS handshake timeouts and HTTPS-proxy configuration errors. It helps distinguish proxy setup from application-level failures. Proxy routing begins in `/github/encode/httpx/httpx/_client.py` and network connection handling is in `/github/encode/httpx/httpx/_transports/default.py`; environment inputs are described in `/github/encode/httpx/docs/environment_variables.md`. Published via `/github/encode/httpx/mkdocs.yml`.
