# Record release behavior and migration history

tags: docs build

This historical release log records additions, changes, fixes, and removals across HTTPX versions. It is an important source when a current behavior looks deliberate or recently changed; historical entries are not a current API contract. `/github/encode/httpx/scripts/sync-version` reads release numbers here, while `/github/encode/httpx/pyproject.toml` embeds a release excerpt in package metadata.
