# Verify public contracts and transport behavior

tags: testing

The root suite tests API helpers, auth, content, configuration, exceptions, CLI, transports, timeouts, and utilities. `/github/encode/httpx/tests/client/` tests client policy and `/github/encode/httpx/tests/models/` checks value objects. `/github/encode/httpx/tests/conftest.py` supplies local apps, server, environment, and certificates.
