# Map the HTTPX repository

HTTPX is a Python HTTP client offering sync and async APIs. `/github/encode/httpx/httpx/` contains public and internal implementation, `/github/encode/httpx/tests/` its behavior suite, `/github/encode/httpx/docs/` the site, and `/github/encode/httpx/scripts/` developer automation. `/github/encode/httpx/pyproject.toml` defines package and tool contracts; `/github/encode/httpx/.github/` contains repository workflows.
