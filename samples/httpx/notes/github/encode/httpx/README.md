# Introduce HTTPX and its supported use

tags: docs api

The project landing page explains synchronous and asynchronous requests, HTTP/1.1 and HTTP/2, installation, docs, and dependencies. Its examples are entry points to `/github/encode/httpx/httpx/__init__.py`; the fuller guide is `/github/encode/httpx/docs/quickstart.md`. Hatch incorporates this README into package metadata through `/github/encode/httpx/pyproject.toml`.
